# FinSight

Smart Personal Finance Management Dashboard.

FinSight is a full-stack personal finance management application that helps users track income, expenses, transactions and financial goals through a modern dashboard.

## Features

- User authentication
- Income and expense tracking
- Transaction management
- Financial dashboard
- Monthly budget tracking
- Financial goals
- Responsive UI
- Dark and light mode

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- CSS
- Lucide React
- Recharts

### Backend

- Java
- Spring Boot
- Spring Data JPA
- REST API
- Maven

### Database

- MySQL
